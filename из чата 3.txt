# 1) Базовые определения (синтез)

* Декогеренция:
  [
  D(x,t)=1-C(x,t).

* Локальный импульс времени / «стрела времени»:
  [
  T(x,t)=\nabla D(x,t).
  ]

* Глобальная когерентность:
  [
  H(t)=\frac{1}{N}\sum_i\Big[C_i(x,t)+\epsilon_{\rm corr}\sum_{j\ne i} w_{ij} C_j(x,t)\Big],

## ⚛️ Шаг 1. Локальный узел когерентности и потенциал (V(C))

### 1.1. Определение

**Локальный узел когерентности** (L_i(x,t)) — минимальная устойчивая область пространства-времени, где поле когерентности
[
\Psi(x,t) = C(x,t)e^{i\varphi(x,t)}
]
сохраняет внутреннюю согласованность (когерентность) дольше характерного времени декогеренции среды.

---

### 1.2. Энергетический функционал

Для одного слоя (одного внутреннего состояния узла):
[
E_\alpha[C,\varphi] =
\int d^3x \left[
A_\alpha V_\alpha(C)

* \frac{1}{2}\kappa_\alpha (\nabla C)^2
* \frac{1}{2}\rho_\alpha C^2(\nabla \varphi)^2

- \mu_\alpha E(1 - C)
  \right].
  ]

где:

* (V_\alpha(C)) — **потенциал когерентности** (внутренний потенциал поля);
* (\kappa_\alpha) — «жёсткость» по когерентности (аналог константы связности поля);
* (\rho_\alpha) — коэффициент инерции фазы;
* (\mu_\alpha E) — взаимодействие с внешним энергетическим полем.

---

### 1.3. Двугорбая форма потенциала

[
V_\alpha(C) = A_\alpha(C-1)^2 + B_\alpha(C-C_\ast)^4,
]

* минимум при (C=1) — **фон** (вакуумное состояние),
* минимум при (C=C_\ast<1) — **локализованный узел** (частица),
* между ними — барьер декогеренции (ΔV), определяющий устойчивость.

---

### 1.4. Уравнение динамики когерентности

В одномерной форме (без фазового члена для чистоты):
[
\frac{\partial C}{\partial t} = -\alpha (1 - C) + \beta \frac{\partial^2 C}{\partial x^2} - \frac{\partial V(C)}{\partial C}.
]

Где:

* первый член (-\alpha(1 - C)) — релаксация к когерентности,
* второй — диффузия когерентности в пространстве,
* третий — градиент потенциала (восстанавливает устойчивое состояние).

---

### 1.5. Линеаризация и формула массы

Рассмотрим малые возмущения вокруг стабильного состояния (C=C_\ast):
[
C(x,t) = C_\ast + \delta C(x,t), \quad |\delta C| \ll 1.
]

Тогда:
[
\frac{\partial \delta C}{\partial t} \approx \beta \nabla^2 \delta C - V''(C_\ast)\delta C.
]

Стационарные волновые решения имеют вид:
[
\delta C \sim e^{i(kx - \omega t)},
]
и из уравнения следует дисперсионное соотношение:
[
\omega^2 = V''(C_\ast) + \beta k^2.
]

Следовательно, **эффективная масса узла (частицы)**:
[
m_\alpha^2 = V''(C_\ast) = \left.\frac{d^2V_\alpha}{dC^2}\right|*{C=C*\ast}.
]

Для заданного потенциала:
[
\frac{d^2V_\alpha}{dC^2} = 2A_\alpha + 12B_\alpha(C - C_\ast)^2,
]
и в точке минимума:
[
\boxed{m_\alpha = \sqrt{2A_\alpha}}.
]

Таким образом, параметр (A_\alpha) управляет **инерцией поля** (массовым масштабом),
а (B_\alpha) и (C_\ast) — **степенью локализации и устойчивостью** (ширина минимума и энергия барьера).

---

### 1.6. Критерий устойчивости

Для устойчивого узла необходимо:
[
V''(C_\ast) > 0, \quad V(C_\ast) < V(1), \quad |C_\ast - 1| \text{ достаточно мало.}
]

Это гарантирует:

1. локальную устойчивость (положительная кривизна),
2. конечную энергию узла,
3. способность узла возвращаться к минимуму при малых возмущениях.

---

### 1.7. Энергия образования и масштаб длины

Энергия дефекта (узла) определяется интегралом:
[
E_{\text{узла}} = \int \left[\frac{1}{2}\kappa_\alpha(\nabla C)^2 + V(C)\right] dx.
]

Для аппроксимации формы (C(x)\sim\tanh(x/\xi)), ширина (\xi \sim \sqrt{\frac{\kappa_\alpha}{V''(C_\ast)}}).
Это даёт естественную длину когерентного узла — **масштаб частицы**.

# 2) Фаза, топология и квантовые числа

## 2.1. Поле фазы — базовая запись

Поле когерентности задаётся комплексным полем
[
\Psi(x,t)=C(x,t),e^{i\varphi(x,t)},
]
где (C\ge0) — амплитуда (степень когерентности), (\varphi\in\mathbb{R}/2\pi) — фазовый угол (элемент (S^1)).
Фаза (\varphi) несёт топологическую информацию и определяет витки/завихрения поля.

## 2.2. Энергетическая часть, зависящая от фазы

Добавляем фазовую кинетическую энергию в функционал слоя:
[
E_\varphi[C,\varphi] = \int d^3x;\frac{1}{2},\rho_\alpha,C^2(x),|\nabla\varphi(x)|^2
]
(пару строчек ранее: уже была в энергетическом функционале).
Этот член штрафует большие градиенты фазы и локализует витки в ядре, где (C) падает.

## 2.3. Топологические объекты: вихри (2D), колец/нитей (3D), Hopf-солионы

* В 2D (или в тонком слое) возможны вихри, где по контуру вокруг ядра фаза имеет целочисленный виток:
  [
  n=\frac{1}{2\pi}\oint_\ell \nabla\varphi\cdot d\ell \in\mathbb{Z}.
  ]
  Энергия одиночного вихря (в 2D) растёт логарифмически с системе размера; в 3D аналогичный объект — линейный объект (вихревая нить), энергия на единицу длины постоянна.

* В 3D возможны локальные (частице-подобные) топологические решения с хопфовой инвариантой (Hopfion). Формально, если (\varphi) и направление амплитуды задают отображение (S^3 \to S^2) (или через нормировку (\hat{\mathbf{n}}(x))), то можно иметь непустые классы, характеризуемые Hopf-инвариантом (Q_H\in\mathbb{Z}) (связность петлей/линковка). Такие объекты — естественные кандидаты на стабильные **топологические частицы** в 3D.

## 2.4. Топологический заряд как физическая величина (интерпретация)

Определим нормировку «заряда» через виток:
[
q = q_0,n,\qquad n=\frac{1}{2\pi}\oint \nabla\varphi\cdot d\ell.
]
Здесь (q_0) — фундаментальная единица заряда в модели (константа калибровки, подлежит калибровке по наблюдаемым).
Таким образом топологический индекс (n) — целочисленный зарядный квант.

## 2.5. Энергетика и профиль ядра

Вязка амплитуды и фазы даёт профиль ядра: в центре (C\to C_\ast) (локализованная декогеренция), на дистанции (r\gg\xi) — (C\to1), а фаза при обходе (2\pi n).
Энергия вихря (приблизительно, 2D):
[
E_{\text{vortex}} \approx \pi \rho_\alpha C_\infty^2 n^2 \ln\left(\frac{L}{\xi}\right) + E_{\text{core}},
]
где (C_\infty\approx1) — фон, (L) — система, (\xi) — ширина ядра, (E_{\text{core}}) — энерго-затрата в области, где (C) падает.

## 2.6. Спин и статистика — возможные механизмы

В тексте файлов спин отнесён к топологии. Здесь даю математически корректные пути, как получить полуцелый (фермионный) и целый (бозонный) спины в рамках топологической модели.

### Механизм A — квантование углового момента (классический)

Топологический узел может иметь внутренний импульс (вращение фазы/структуры), который даёт момент импульса:
[
\mathbf{J} = \int d^3x; \mathbf{r}\times \mathbf{p}(x),
]
где (\mathbf{p}) выражается через поля (C,\varphi). Для некоторых симметрий (например, кручёные/скрученные конфигурации) интеграл даёт полуцелые или целые значения в единицах (\hbar) при соответствующей нормировке.

### Механизм B — связность с фермионными нулевыми модами (индексный механизм)

Чтобы получить Ферми-статистику (антисимметрию), стандартная стратегия: положить фермионную «тестовую» полевую двоичную структуру (Дирак-фермион) на фоне топологического узла и показать существование нулевой локализованной моды Дирака (Jackiw–Rebbi / Callan–Harvey типы). Ключевые элементы:

* Ввести эффективный Дираковский оператор ( \slashed{D}[A,\Phi] ) на фоне скалярного/фазового поля (\Phi) (здесь (\Psi) играет роль).
* Применить теорему индекса (Atiyah–Singer / похоже) — нуль-моды связаны с топологическим числом узла.
* Наличие нечётного числа нулевых мод может обеспечить превращение солитона в объект с фермионным статистическим фактором (под 2π-поворот объект может набирать минус знак).

Это стандартный путь в топологической физике солитонов → фермионов (см. Jackiw–Rebbi, Rubakov–Callan и др.). В нашей модели это означает: чтобы иметь фермионоподобные частицы, нужно либо (i) включить явные фермионные поля и изучить их нулевые моды на фоне (\Psi), либо (ii) доказать эквивалентность статистики через Finkelstein–Rubinstein правила для многочастичных конфигураций (квантование конфигурационного пространства солитонов).

### Механизм C — Hopf-солионы и полупространственный спин

Hopf-солионы могут иметь нечётную трансформацию под 2π/rotations; через конструкцию связки/линковки можно получить квазичисла, эквивалентные полуцелым спинам. Здесь требуется аккуратная работа с кручением и выходной нормировкой момента импульса.

**Вывод:** утверждать автоматически фермионность через только (C,\varphi) нельзя — нужен дополнительный шаг (Dirac-поля или index-theorem аргументация). Но модель даёт все предпосылки (топологические классы, локализованные нулевые моды) для такого получения.

## 2.7. Калибровочные поля как поле связи фаз

Если фазовые различия между соседними узлами приводят к энергийному штрафу, можно ввести «фазовую связь»/калибровочное поле (A_\mu) через минимальное замещение:
[
\nabla\varphi \mapsto (\nabla\varphi - q_0 \mathbf{A}),
]
и добавить Maxwell-подобные члены для (A_\mu). В пределе слабых флуктуаций это даёт эффективную калибровочную теорию, где носитель взаимодействия — колебания (A_\mu). Тогда ток, связанный с фазой, (j^\mu \propto \rho C^2(\partial^\mu\varphi - q_0 A^\mu)), играет роль в уравнениях поля.

Это даёт путь к интерпретации электромагнитного/калибровочного взаимодействия как следствия фазовой корреляции между узлами.

# ⚙️ Шаг 3. Вариационные уравнения и динамика элементарного узла

## 3.1 Лагранжева плотность поля когерентности

Полная плотность (одного сорта α):

[
\mathcal{L}*\alpha =
\frac{1}{2}\rho*\alpha,C^2(\partial_t\varphi)^2

* \frac{1}{2}\rho_\alpha,C^2(\nabla\varphi)^2
* \frac{1}{2}\kappa_\alpha (\nabla C)^2
* V_\alpha(C)

- \mu_\alpha E(1 - C).
  ]

При желании можно добавить затухание (-\gamma_\alpha \dot{C}) или связь с внешним потенциалом, но пока сохраняем консервативный вариант.

---

## 3.2 Вариации по (C) и (\varphi)

### (а) Вариация по амплитуде (C)

[
\frac{\partial \mathcal{L}}{\partial C}

* \partial_i!\left(\frac{\partial \mathcal{L}}{\partial(\partial_i C)}\right)
* \partial_t!\left(\frac{\partial \mathcal{L}}{\partial(\partial_t C)}\right) = 0.
  ]

Так как (\mathcal{L}) не содержит (\partial_t C) (в простейшей форме), получаем:

[
-\kappa_\alpha \nabla^2 C

* \rho_\alpha C(\dot{\varphi}^2 - |\nabla\varphi|^2)

- \frac{dV_\alpha}{dC}
- \mu_\alpha E = 0.
  ]

Это **уравнение амплитуды** — определяет профиль (C(x,t)) и, в статическом случае, ядро частицы.

---

### (б) Вариация по фазе (\varphi)

[
\partial_\mu\left(
\frac{\partial \mathcal{L}}{\partial(\partial_\mu\varphi)}
\right)=0,
]

что даёт **уравнение непрерывности тока когерентности**:

[
\partial_t (\rho_\alpha C^2 \dot{\varphi})

* \nabla!\cdot(\rho_\alpha C^2 \nabla\varphi)=0.
  ]

Определяя плотность и ток:
[
n_\alpha = \rho_\alpha C^2 \dot{\varphi},\qquad
\mathbf{j}*\alpha = \rho*\alpha C^2 \nabla\varphi,
]
получаем классическую форму:
[
\partial_t n_\alpha + \nabla!\cdot \mathbf{j}_\alpha = 0.
]
Это — **закон сохранения топологического заряда/потока когерентности**.

---

## 3.3 Связь с уравнением Шрёдингера-типа

Если собрать (C) и (\varphi) в одно поле (\Psi=C,e^{i\varphi}), можно восстановить динамику, аналогичную нелинейному Шрёдингеру (или Гросса–Питаевского):

[
i\rho_\alpha ,\partial_t \Psi
= -\frac{\kappa_\alpha}{2}\nabla^2 \Psi

* \frac{1}{2\rho_\alpha}\frac{dV_\alpha}{dC}\frac{\Psi}{C}

- \mu_\alpha E,\Psi.
  ]

В этом виде виден квантово-механический аналог:

* (\rho_\alpha) играет роль обратной «постоянной массы»;
* нелинейность через (V(C)) — собственный потенциал частицы;
* (E) — внешний источник энергии.

Так рождается **эффективное квантовое уравнение поля когерентности**, к которому обычное уравнение Шрёдингера является линейным пределом при (V(C)\approx m_\alpha^2(C-1)^2/2).

---

## 3.4 Динамика малых возмущений

Линеаризуя систему вокруг стационарного решения (C=C_\ast), (\varphi=\varphi_0+\delta\varphi):

[
\rho_\alpha C_\ast^2,\partial_t^2\delta\varphi

* \rho_\alpha C_\ast^2,\nabla^2\delta\varphi = 0,
  ]

что соответствует **волновому уравнению** с фазовой скоростью (v_\varphi = 1) (в нормированных единицах).
Таким образом, фазовые колебания — это **фонон-/бозоноподобные возбуждения** (носители взаимодействий), а амплитудные колебания — **массивные моды** (частицы-узлы).

---

## 3.5 Энергия и импульс

Из тензора энергии-импульса:

[
T^{00} = \frac{1}{2}\rho_\alpha C^2 (\dot{\varphi}^2 + |\nabla\varphi|^2)

* \frac{1}{2}\kappa_\alpha|\nabla C|^2 + V(C) - \mu_\alpha E(1 - C),
  ]
  [
  T^{0i} = \rho_\alpha C^2 \dot{\varphi},\nabla_i\varphi.
  ]

Это задаёт плотность энергии и поток импульса поля когерентности. Интегралы по всему пространству дают **энергию и полный импульс частицы**.

# A. Взаимодействия как эффект фазовой связи (калибровочная теория)

## A.1 Начало: дискретная сеть фаз и энергия связи

Пусть узлы образуют сеть (решётку), и между узлами (i,j) есть энергия связи, зависящая от фаз:

[
E_{\text{int}} = -\sum_{\langle i,j\rangle} J_{ij}; C_i C_j \cos\big(\varphi_i - \varphi_j\big),
]

(аналог Джозефсона / XY-модели; (J_{ij}\propto w_{ij})). Это зеркало тезисов о межузловых корреляциях.

Для небольших фазовых разностей (малые возмущения) используем разложение:

[
\cos(\varphi_i-\varphi_j)\approx 1 - \tfrac12(\varphi_i-\varphi_j)^2.
]

Тогда вклад в энергию ~ (\tfrac12\sum J_{ij}C_iC_j(\varphi_i-\varphi_j)^2). В непрерывном пределе ((i\to x)) это даёт член (\propto C^2(\nabla\varphi)^2) — уже присутствовавший в функционале.

## A.2 Введение поля связи (A_\mu) (минимальное замещение)

Если у фазы есть «локальная» симметрия под сдвиг (\varphi(x)\mapsto\varphi(x)+\alpha(x)), и связь между узлами допускает независимые локальные фазовые преобразования, вводим калибровочную связь (A_\mu) как компенсатор:

в пространственном компоненте:
[
\nabla\varphi ;\mapsto; (\nabla\varphi - q_0 \mathbf{A}),
]
в полной 4-формации:
[
\partial_\mu\varphi ;\mapsto; D_\mu\varphi \equiv \partial_\mu\varphi - q_0 A_\mu.
]

(q_0) — константа нормировки (основная «зарядовая» единица в модели).

Энергетический член фазовой кинетики становится:
[
\frac12\rho C^2 |D_\mu\varphi|^2.
]

## A.3 Полный эффективный лагранжиан (абелевский случай)

[
\mathcal{L} = -\frac14 F_{\mu\nu}F^{\mu\nu}

* \frac12\rho C^2 (D_\mu\varphi)(D^\mu\varphi)

- \frac12\kappa(\nabla C)^2 - V(C) + \mu E(1-C),
  ]
  где (F_{\mu\nu}=\partial_\mu A_\nu-\partial_\nu A_\mu).

Это — минимальный лагранжиан объединяющий поле связи и поле когерентности.

## A.4 Токи и уравнения Максвелла-типа

Вариация по (A_\mu) даёт уравнения поля:

[
\partial_\nu F^{\nu\mu} = j^\mu,
]
[
\text{где } \quad j^\mu = q_0,\rho,C^2,D^\mu\varphi = q_0,\rho,C^2(\partial^\mu\varphi - q_0 A^\mu).
]

Это — **закон сохранения заряда**: (\partial_\mu j^\mu=0) вследствие уравнения для (\varphi). Значит, фаза генерирует текущий источник поля (A_\mu).

## A.5 Электростатика/силы: как появляется «Кулоновская» часть

В стационарном (медленном) пределе для маленьких вариаций и распределении топологического заряда (n(x)) можно получить потенциалное поведение ( \sim 1/r ) для поля (A_0) в 3D — то есть эффективное «кулоновское» взаимодействие между точечными топологическими зарядами (витками фазы). В 2D взаимодействие логарифмическое (XY-модель). Эффективный закон силы зависит от размерности и экранования (наличие фонового (C) даёт масса увеличения/экранирования — аналог эффекта Хиггса, см. ниже).

## A.6 Массовая генерация для калибровочного поля (Higgs-подобный эффект)

Если (C) замкнут в ненулевое среднее (C\to C_\infty) и фаза «фиксируется», то уравнение для (A_\mu) содержит массовый член (\propto q_0^2\rho C_\infty^2 A_\mu): это даёт массовость носителя взаимодействия (экранование). В противоположность — в областях где (C\to0) (локальная декогеренция) поле остаётся безмассовым и дальнодействующим.

Таким образом: радиус действия взаимодействия связан с локальной амплитудой когерентности — естественный механизм экранования/конфайнмента.

## A.7 Неформальный вывод (w_{ij}\to A_\mu)

Коротко: дискретные связи (J_{ij}) в пределе плотной сети описываются калибровочной связью; фазовые разности переводятся в ковариантные производные с компенсатором (A_\mu). Константы (J_{ij}) определяют эффективную упругость и, через неё, значение (\rho) и коэффициент связи (q_0).

## A.8 Наблюдаемые следствия (для микромира)

* Заряд (q) — топологический виток (n) умноженный на нормировку (q_0).
* Электромагнитная сила ≈ обмен колебаниями поля (A_\mu) — угасает в областях с большим (C) (массовое поведение).
* Возможность непросто-абелевых (не-коммутирующих) калибровок при многослойной структуре: если фазы слоями имеют матричные взаимосвязи (K_{\alpha\beta}), расширяется до не-абелевых (A_\mu^a) и структур SU(N).

## B.1 Противоречие: «масса» и разные динамики амплитуды (C)

**Что было:**

* В шаге 1 (линейная стабильность) мы использовали уравнение первого порядка по времени (диффузионное / релаксационное) и получили (m_\alpha^2 = V''(C_\ast)) (или (m_\alpha=\sqrt{2A_\alpha}) при выбранном потенциале).
* В шаге 3 (вариационный лагранжиан) амплитуда (C) получила уравнение без инерционного члена ((\partial_t C)^2)) — мы линеаризовали и говорили об амплитудных и фазовых модах; при консервативной версии с добавлением кинетики для (C) масса моды будет (m^2 = V''(C_\ast)/\chi) (где (\chi) — коэффициент при ((\partial_t C)^2)).

**Как согласовать (рекомендую в документе):**

1. **Фиксируем два режима движения амплитуды (C):**

   * *Режим A (диссипативный, макроколебания медленны):* первое приближение — релаксационная/диффузионная динамика (\partial_t C = -\Gamma \delta F/\delta C). В этом приближении масса как параметр частоты можно записать прямо через (V''(C_\ast)) (в единицах, где (\Gamma=1)). Это удобно для численных симуляций релаксации/статических профильных расчётов.
   * *Режим B (инерционный, консервативный):* добавить кинетический термин (\tfrac12\chi(\partial_t C)^2) в лагранжиан. Тогда нормальная частота осцилляций вокруг минимума даёт ( \omega^2 = V''(C_\ast)/\chi + \dots).
2. **Нормировка:** принять для документирования «рабочую нормировку» (\chi=1) (или указать символически), тогда предыдущая формула (m_\alpha^2=V''(C_\ast)) остаётся валидной. При желании можно держать (\chi) как параметр «инерции амплитуды» и следить при калибровке.

**Итого:** нет противоречия — есть два физически разных режима. Фиксируем это в тексте и вводим параметр (\chi) если нужны колебательные режимы.

## B.2 Противоречие: использование первой- и второй-порядка по времени

Схожее замечание: часть уравнений писалась как (\partial_t C = \dots) (первый порядок), часть — как волновое/лапласово уравнение для фазы (второй порядок).
**Решение:** различать «аморфный релаксационный» член (экспоненциальное затухание декогеренции) и «фазовые волны» (инерционные). В физическом смысле фаза имеет инерционную динамику (волны), а амплитуда часто релаксирует через взаимодействие с окружением. Зафиксируем это в документе как принцип.

## B.3 Нормы факторов (\rho,\kappa,\beta)

Ранее в разных местах использованы (\beta) и (\kappa) для пространственной жёсткости; важно согласовать:

* пусть в лагранжиане коэффициент при ((\nabla C)^2) = (\kappa),
* во фронтальном диффузионном уравнении коэффициент при (\nabla^2C) = (\beta),
  и связать их при желании: (\beta) — положенный параметр релаксационного оператора, (\kappa) — механическая жёсткость в вариационном представлении; при консервативной нормировке (\beta = \kappa/\Gamma) (если (\partial_t C = -\Gamma \delta E/\delta C)). Записать эту связь — и больше путаницы не будет.
